# Зонк — онлайн-сервер

Сервер без внешних зависимостей (только Node.js 18+). В этой папке:

- `index.js` — подбор соперника по ставке, комнаты друзей по коду, вся логика партии;
- `ws.js` — WebSocket;
- `shared/` — правила игры (те же, что в приложении);
- `public/index.html` — веб-версия игры: откройте адрес сервера в браузере и играйте.

## Запуск на Render (бесплатно)

1. Зарегистрируйтесь на github.com и создайте репозиторий `zonk-server` (Public или Private).
2. В репозитории: **Add file → Upload files** → перетащите ВСЁ содержимое этой папки
   (вместе с папками `shared` и `public`) → **Commit changes**.
3. Зарегистрируйтесь на render.com через «GitHub».
4. **New → Web Service** → выберите репозиторий `zonk-server`.
5. Заполните:
   - Name: `zonk-vinstar`
   - Region: Frankfurt
   - Runtime / Language: Node
   - Build Command: `npm install`
   - Start Command: `node index.js`
   - Instance Type: **Free**
6. **Deploy Web Service**. Через 1–2 минуты появится адрес вида `https://zonk-vinstar.onrender.com`.
7. Проверка: откройте `https://<ваш-адрес>/health` — должно быть `{"ok":true,...}`.

Если имя `zonk-vinstar` занято и адрес получился другим — впишите его в игре:
**Настройки → Онлайн → Адрес сервера**.

## Особенности бесплатного тарифа

- После 15 минут без игроков сервер засыпает; первый вход будит его примерно за минуту
  (игра показывает «Будим сервер…»).
- Перезапуск сервера обрывает текущие партии (балансы хранятся на телефонах игроков).

## Локально

```
node index.js        # порт 8080, или PORT=9000 node index.js
```
